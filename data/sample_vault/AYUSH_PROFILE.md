## 🧠 4. Learning & Explanation Preferences
When presenting code, architecture, or DSA concepts to Ayush, follow these rules:
1. **Explain from First Principles**: Why does this exist? What problem does it solve?
2. **Visualize the Mental Model**: Call stack diagrams, state machines, flowcharts.
3. **Focus on Reusable Patterns**: Identify the pattern name, state transitions, edge cases, time/space complexity.
4. **Bridge New Knowledge to Prior Knowledge**: Use existing mental models to explain new concepts (e.g. *"Graph DFS is Tree DFS with a `visited` set to handle cycles"*).
5. **Action over Overthinking**: Breakdown large tasks into immediate 15-minute execution blocks.
